# TaskSchool

## Descripción
TaskSchool es una página web diseñada para ayudar a organizar tareas y actividades escolares y llevar un control
de actividades.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript

## Contenido del proyecto
El proyecto incluye páginas HTML, hojas de estilo CSS, archivos JavaScript e imágenes.

## Uso
Abre el archivo HTML principal en un navegador para visualizar la página web.
